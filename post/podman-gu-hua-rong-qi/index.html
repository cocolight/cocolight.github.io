Podman 固化容器

2026-10-03 • 3 分钟阅读 • IPTV • immortalwrt · podman

修复：把存储根挪到持久分区

编辑 /etc/containers/storage.conf（这个文件在 /etc 下，本身是持久的）：

[storage]
driver = "overlay"
graphroot = "/overlay/podman/storage"
runroot  = "/overlay/podman/run"

然后重新拉取并创建容器（旧的无用 tmpfs 数据重启即清）：

podman rm -f IPTV-API
podman pull docker.io/guovern/iptv-api:latest
# 用你原来的 run 命令重建（记得加 --network=host 省掉 NAT 规则）

确认改对了：podman info | grep -A1 graphRoot 应显示 /overlay/podman/storage。

这个文件正好印证了我前面的判断——配置“看起来”指向持久路径，实际全落进了内存。关键在这两个值：

runroot  = "/run/containers/storage"
graphroot = "/var/lib/containers/storage"

而你的 inspect 实际路径却是 /tmp/lib/containers/storage 和 /tmp/run/containers/storage。为什么对不上？因为 ImmortalWrt 上 /var 是软链到 /tmp，/run 是 tmpfs 内存盘：

  • graphroot = /var/lib/containers/storage → /var→/tmp → 实际是 /tmp/lib/containers/storage**（内存）**​
  • runroot = /run/containers/storage → /run 是 tmpfs → 实际是 /tmp/run/containers/storage**（内存）**​

所以你这份“没改过的默认配置”，在 ImmortalWrt 上等价于把镜像和容器全塞进了 RAM——和你之前看到的现象完全吻合。

自己验证一下（别光信我）

ls -ld /var /run          # 会看到 /var -> /tmp，/run 是 tmpfs 挂载
df -h /tmp /overlay       # /tmp 是 tmpfs（内存），/overlay 是持久闪存/硬盘

修复：只改 graphroot

文件里自带注释也说了 runroot 是“临时状态”、就该在 tmpfs，所以 runroot 不动，只把 graphroot 指到真正的持久路径：

# 原值（实际解析进内存，删掉/改掉）：
# graphroot = "/var/lib/containers/storage"

# 改为：
graphroot = "/overlay/podman/storage"

改完后的完整关键段：

[storage]
driver = "overlay"
runroot = "/run/containers/storage"          # 保持，tmpfs 放临时状态是对的
graphroot = "/overlay/podman/storage"        # ← 改这一行，落到持久盘

应用步骤

mkdir -p /overlay/podman/storage

# 旧容器/镜像现在在内存里，直接删（reboot 也会没，不心疼）
podman rm -f IPTV-API

# 重新拉取——这次会落到 /overlay/podman/storage（持久）
podman pull docker.io/guovern/iptv-api:latest

# 用原 run 命令重建，建议加 --network=host 省掉 NAT 规则
# （记得先把之前那个 /iptv-api/output 挂载源目录建好，否则又报 invalid mount type）

# 确认生效
podman info | grep -A1 graphRoot
#   应显示 /overlay/podman/storage

为什么不动 runroot：它放的是运行时锁/pidfile 等瞬态数据，放 tmpfs 是正确的（文件注释也明确这么建议），挪到闪存反而无意义地增加写入。只有 graphroot（镜像层 + 容器可写层）需要持久化。

改完这行，镜像和容器就固化在 /overlay 了，重启不丢，也不占 RAM；再配个 rc.local 里的 podman start IPTV-API 就能开机自启。
