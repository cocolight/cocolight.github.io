华为CU接口速查-脱敏版

2026-10-05 • 16 分钟阅读 • IPTV • iptv · immortalwrt

华为 CU 体系接口速查（IPTV 认证 / EPG / 频道表）· 脱敏版

CU = China Unicom（联通）定制，跑在华为 IPTV 机顶盒（EC6109U 系列）上的 EPG + 认证体系。
本文全部字段/值取自一次 eth1 透明网桥抓包（eth1_stb_<日期>.pcap，TCP stream 20），
帧号、参数、Token 均可在 pcap 中复核。

:warning: 本文件为脱敏版：账号、STBID、MAC、各类 Token / SessionID / Authenticator 均替换为
占位符，服务器 IP 按「段内保留结构、主机位打码」处理。原文（含真实值）见同目录非脱敏版本。
占位符命名规则见文末 §8 脱敏对照表。

0. 体系模型（先理解两件事）

① STB 侧的 JS 原生桥 Authentication

EPG 页面运行在机顶盒内置浏览器里，通过一个原生对象读写本地配置：

方法 作用
Authentication.CUGetConfig(key) 读机顶盒本地配置项（STBID、mac、tempKey、Lang…）
Authentication.CUSetConfig(key, value) 写配置项，也用于把服务器下发的数据（频道表等）缓存到本地

服务器返回的很多“接口响应”其实是 HTML + JS 片段——真正的数据藏在
CUSetConfig('key','value') 这一句里。解析时抓 CUSetConfig(...) 即可，不用解析 HTML。

② 各页面靠「表单自动提交」串联

每个响应页面 <body onload=DoXXX()> 自动 submit 到下一个接口，形成开机认证链：

 authLoginHWCU.jsp → ValidAuthenticationHWCU.jsp → getchannellistHWCU.jsp
    → ServicesEntryHWCU.jsp → indexHWCU.jsp → PreDealHWCU.jsp → Category.jsp

3. 关键接口详解

3.1 GET /EPG/jsp/AuthenticationURL

  • Query：UserID=<UserID>（@ 需 URL 编码为 %40）、Action=Login
  • 响应：登录页 HTML，<body onload=DoAuth()>。

3.2 POST /EPG/jsp/authLoginHWCU.jsp ★发 Token 的地方

  • 请求体（仅 2 字段）： 
     UserID=<UserID-URL编码>&VIP=
  • 响应 = 一段 JS（NOT 数据 JSON），关键两行： 
     var EncryptToken = "<EncryptToken>";
 document.authform.Authenticator.value = Authentication.CUGetAuthInfo(EncryptToken);

    Authenticator 由机顶盒本地用 CUGetAuthInfo(EncryptToken) 算出（硬件/密钥参与），
    无法离线复算 —— 想重放必须原机或抓原包。

3.3 POST /EPG/jsp/ValidAuthenticationHWCU.jsp ★核心认证

  • 请求体（17 字段，结构示例）： 
     UserID=<UserID-双编码>&Lang=1&SupportHD=1&NetUserID=
 &Authenticator=<Authenticator-129hex>&STBType=EC6109U_nmglt
 &STBVersion=19.2.0-LNML21.SPC002.B011&conntype=4
 &STBID=<STBID>&templateName=defaultok
 &areaId=<areaId>&userToken=<EncryptToken>
 &userGroupId=16&productPackageId=-1
 &mac=<STB-MAC-URL编码>
 &SoftwareVersion=19.2.0-LNML21.SPC002.B011&VIP=

    注意 UserID 在这里被二次编码：@ → %40 → %2540（% 再编成 %25）。

  • 响应（gzip，约 10.9KB）48 条 CUSetConfig，关键：
key 值
isSucessed true
UserToken <UserToken> ← 后续接口用
EPGDomain http://10.11.37.165:33200/EPG/jsp/defaultok/en/Category.jsp
ManagementDomain http://10.11.33.34:37020/acs
UpgradeDomain http://10.11.37.82:9030
NTPDomain 10.11.33.75（备 10.11.33.76）
SQARtcpPort 8027
SessionID <SessionID>
subNetId 8601
areaid / EPGGroupNMB / UserGroupNMB / PackageIDs <areaId> / defaultok / 16 / -1

:warning: 纠正旧结论：早期把 productPackageId=-1 当作“业务退订”的根因。
实测证明它属正常——本次该字段为 -1 仍认证成功、拿到完整频道表。
真因是抓包点在旁路（见抓包笔记）。

3.4 POST /EPG/jsp/getchannellistHWCU.jsp ★★频道表本体

  • 请求体（7 字段）： 
     conntype=4&UserToken=<UserToken>
 &tempKey=<tempKey>&stbid=<stbid短号>
 &SupportHD=1&UserID=<UserID-URL编码>&Lang=1

    tempKey 来自机顶盒本地 CUGetConfig('tempKey')；stbid 为 STBID 派生的短号（示例 150008，取 STBID 中段）。

  • 响应（gzip，约 190KB）= 频道表： 
     CUSetConfig('ChannelCount','<N>');
 CUSetConfig('Channel','ChannelID="20000106",ChannelName="CCTV-1高清",…');   ×N
  • 请求来源：由 ValidAuthenticationHWCU.jsp 响应页的隐藏表单自动提交（字段一一对应）。

3.5 POST /EPG/jsp/ServicesEntryHWCU.jsp

  • 请求体：lang=1
  • 响应：CUSetConfig('ServiceEntry','URL="http://10.11.37.165:33200/EPG/jsp/getServicesEntryHWCTC.jsp?action=PortalEPGURL",HotKey="272",…')
    → 然后 document.location='indexHWCU.jsp?lang=1'。

3.6 indexHWCU.jsp / PreDealHWCU.jsp / Category.jsp

  • indexHWCU.jsp?lang=1 → 首页框架；
  • PreDealHWCU.jsp?directPlay=0&lastChannelNo=null&FIRSTPAGE=defaultok/en/Category.jsp → 预处理/选首页；
  • Category.jsp?directplay=0&lastchannelNo=null&isComeFromPredeal=1&joinFlag=0 → 频道分类页（GUI 导航；频道数据在 3.4，不在这里）。

  • Device.X_00E0FC.IsEncryptMark = 0（业务流未加密）。

4. Token / 标识字典

名称 值（本次实测，已脱敏） 生命周期 / 来源
UserID（宽带账号） <UserID> 固定
STBID <STBID> 固定（含 OUI 00E0FC）
mac <STB-MAC> 固定（机顶盒有线 MAC）
EncryptToken <EncryptToken> 会话级，authLoginHWCU 下发
userToken(请求) 同 EncryptToken 会话级
UserToken(响应) <UserToken> 会话级，认证成功下发，后续接口凭证
tempKey <tempKey> 会话级，本机 CUGetConfig
SessionID <SessionID> 会话级
Authenticator <Authenticator>（129 hex） 本机计算，不可离线复算

结论：这套认证无法离线重放（Authenticator 由机顶盒本地密钥生成）。
要拿最新频道表 → 只能在机顶盒重认证时抓原包，或直接用已抓到的频道表直到业务变更。

  • 回看 URL 内嵌 accountinfo 令牌（GuardEncType=2），会话级、会过期。

7. 复现要点

  1. 抓包点必须在链路中间（否则只能看到组播，拿不到本认证链）→ 见 IPTV抓包笔记.md。
  2. 抓包窗口覆盖 开机 → 认证 → 打开频道列表 → 切台（≥6 分钟）。
  3. 定位：
 tshark -r X.pcap -Y "http.request" -T fields -e frame.number -e ip.dst -e http.request.uri

→ 找 getchannellistHWCU 所在 tcp.stream。
4. 切流 + 导出（gzip 自动解压）：

tshark -r X.pcap -Y "tcp.stream==N" -w s.pcap
tshark -r s.pcap --export-objects http,out
  1. 从响应里 grep CUSetConfig('Channel' 提取频道；ChannelCount 校验总数。

8. 脱敏对照表

占位符 真实值的形态 脱敏理由
<UserID> 12 位数字 + @tv 宽带账号，可关联到具体用户
<STBID> 28 位十六进制串 设备序列号，可关联到具体终端
<STB-MAC> xx:xx:xx:xx:xx:xx 设备网卡物理地址
<EncryptToken> 32 位十六进制串 会话令牌
<UserToken> 24 位大小写混合串 会话令牌
<tempKey> 32 位十六进制串 会话令牌
<SessionID> 32 位大写字母数字串 会话标识
<Authenticator> 129 位十六进制串 本机签名，含设备密钥信息
<areaId> 4 位数字 地市区域编码（轻度敏感）
<N> 整数 频道总数（属业务规模信息）

保留未脱敏的项（含理由）：

项 值 保留理由
运营商内网 IP 段 10.11.x.x 私网地址，RFC1918，不指向具体个人
组播地址段 239.125.x.x 组播地址，同上
域名 / 端口 :8082 :33200 等 协议常量，无个人标识
软件版本 / 机型 EC6109U_nmglt、19.2.0-… 公有固件版本号
公共参数 lang=1、conntype=4、subNetId=8601 协议字段

如需更严格脱敏（连 10.11.x.x / 239.125.x.x 段也打码为 <内网> / <组播>），
可直接全局替换；但那样会牺牲笔记的可读性与可验证性。
